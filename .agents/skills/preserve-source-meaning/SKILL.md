技能自身的署名与来源说明：鲜唯佳与 AI 协作。用户提供问题选择、约束、纠正与取舍；AI 起草抽象结构、字段与测试。方法候选不代表已验证现实效果，也不代表临床或投资资质。此说明仅描述本技能，不可照搬为新任务材料的作者或贡献；新材料逐项按其证据归属，未知保持未知。第三方方法保留原作者归属。

遵循当前用户授权与任务范围。已有明确授权的工作继续执行；仅在缺少必要授权时暂停相应外部动作。本技能不单独授权发布、付款、联络第三方或删除原始资料。

输出可复核结果时，记录版本、输入范围、证据引用、假设、决定、限制及实际执行状态（passed / failed / blocked / inconclusive / not_run）。预测本身的 pending 或未命中状态与技能执行状态分开。未知数值用 null 并保留原因；真实零、未知、未核实、不可访问和不适用不得合并。私有来源与公开合成案例分开，失败与旧版本不被覆盖。

### 触发器

总结资料、引用研究、填表或改写需求时，出现相近概念互换、单位变化、数值缺失、原话被扩大解释，或用户纠正“我说的是 A，不是 B”时。

### 输入

- 原始材料与待核验的摘要、表格或结论
- 指标定义、单位、对象、时间范围与适用条件
- 用户明确纠正及其对应位置
- 输出格式与允许省略的内容

### 步骤

1. 对照源材料建立字段清单：原词、定义、对象、单位、时间范围、条件、出处和可访问状态。
2. 检查摘要是否把一个指标换成另一指标、把关联换成因果、把局部结果扩大到总体，或删掉重要限定词。
3. 收到纠正时修正准确的对应字段，并检查同一误读是否已传播到其他结论、图表和建议；不因一次纠正推翻全部内容。
4. 对缺失项使用 `value: null` 和 `state: unknown/unverified/inaccessible/not-applicable`。明确真实为零时才用数值 `0`。
5. 只进行有合法对应规则的换算；记录换算方法。无法确定指标含义时提出最小问题或保留未知。
6. 输出已修正结果、具体差异、仍未确定的字段，以及受该修正影响的下游结论。

### 输出

`source_fidelity_report`：字段、源定义、旧表述、新表述、错误类型、出处、下游影响。

`verified_record`：原始字段、规范字段、值、单位、状态、证据与转换记录。

### 失败条件

- 用含义相近的词替代原始指标但不说明
- 未读到来源却声称已核实
- 用 0、默认值或模型推测填补未知
- 用户只纠正一处含义，却顺带改写其未改变的意图

### 验证

完成任务后用 [合成案例](references/test-cases.md) 检查成功、边界和反例。测试用例不等于通过记录；未运行标记 not_run。

### 来源与贡献

用户曾明确纠正 AI 把两个不同指标混为一谈。公开版保留这一纠正模式，去掉私人领域细节。指标字典、未知状态协议和传播检查是 AI 的工程化扩展；未主张用户曾独立设计数据类型规范。
