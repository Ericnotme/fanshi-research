技能自身的署名与来源说明：鲜唯佳与 AI 协作。用户提供问题选择、约束、纠正与取舍；AI 起草抽象结构、字段与测试。方法候选不代表已验证现实效果，也不代表临床或投资资质。此说明仅描述本技能，不可照搬为新任务材料的作者或贡献；新材料逐项按其证据归属，未知保持未知。第三方方法保留原作者归属。

遵循当前用户授权与任务范围。已有明确授权的工作继续执行；仅在缺少必要授权时暂停相应外部动作。本技能不单独授权发布、付款、联络第三方或删除原始资料。

输出可复核结果时，记录版本、输入范围、证据引用、假设、决定、限制及实际执行状态（passed / failed / blocked / inconclusive / not_run）。预测本身的 pending 或未命中状态与技能执行状态分开。未知数值用 null 并保留原因；真实零、未知、未核实、不可访问和不适用不得合并。私有来源与公开合成案例分开，失败与旧版本不被覆盖。

### 触发器

准备购买课程、投入长期训练或更换学习方式，但缺少当前能力测量；用户要求先找到薄弱环节再决定方案时。

### 输入

- 明确目标与截止时间
- 当前可用的任务或测评、评分标准和完成条件
- 历史成绩及其日期，只作为背景
- 时间、通勤、反馈频率与可承担投入等约束
- 候选方案的已核实信息与尚待确认信息

### 步骤

1. 用当前适用的题目或任务进行基线测量，记录环境、时间、评分标准和限制。旧成绩不能替代当前测量。
2. 将错误按具体能力与失误类型归类，区分不会、做不稳、速度不足、反馈不足等可检验原因。
3. 为优先短板设计最小试用：一段练习、一节实际授课老师的试听或一次带反馈的任务，观察能否定位问题并改进。
4. 比较方案对真实短板的覆盖、反馈质量、安排和可持续性，核对具体授课地点与老师；未知报价或效果保持未知。
5. 先提出阶段性投入与复测条件。购买、报名和其他承诺由用户决定并授权。
6. 在预先约定的复测点使用可比较任务检查变化，再决定继续、调整或停止。没有复测数据就不报告有效。

### 输出

`baseline_profile`：当前测量、任务条件、短板、证据、测量限制。

`trial_plan`：最小试用、期望观察、复测条件、方案比较、待用户决定项。

### 失败条件

- 没有基线就给出个人提分承诺或精确达标时间
- 仅凭品牌、总课时或过去成功案例决定报名
- 把“愿意先测”写成“已经证明这种方法有效”
- 未经授权报名、付款或作长期承诺

### 验证

完成任务后用 [合成案例](references/test-cases.md) 检查成功、边界和反例。测试用例不等于通过记录；未运行标记 not_run。

### 来源与贡献

用户明确选择先测当前薄弱环节再考虑报班；已读聊天还显示其追问上课频率和具体选课条件。它是采纳的决策方向，没有完成测评或效果验证的证据。分型、试用和复测流程由 AI 起草。
