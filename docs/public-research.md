# 公开研究示例：售价上升是否足以证明盈利改善？

在本地 `dist/index.html` 选择“公开研究示例”。数据与来源链保存在 `examples/public-phone-pricing.json`，可从页面单独导出。它是核对公开披露后编排的研究案例，不调用合成证据评价器，也不提供真实来源自动导入、收益回测或交易接口。原合成样例及测试保留。

## 来源到命题

发现入口是[财新公开页面](https://weekly.caixin.com/2026-10-10/102491890.html)的标题与摘要。仅将其作为提问线索，未读取付费全文，没有把报道当成手机业务毛利率的一手证据。

第一条推论收窄为“小米手机 ASP 上升足以证明同期手机业务毛利率改善”。[小米中报](https://ir.mi.com/static-files/b903a881-8143-44a3-b759-703653bbb043)的手机业务数据给出反例，见 PDF 零索引19、23页（阅读器第20、24页；印刷第18、22页）。案例中的 ASP、出货量与毛利率均对比2026上半年与2025上半年。ASP包含产品组合变化，不是同款涨价；毛利率不是净利润。这一反例不证明9月新品提价的因果效应，也不能外推所有厂商。

第二条命题“合同重定价时差能否产生超额收益”保持未知。[美光准备稿](https://s25.q4cdn.com/621799436/files/doc_financials/2026/q4/Q4-FY26-Prepared-Remarks.pdf)第3、4页的合同及定价陈述支持提出研究问题，不等于市场尚未计价。合同份数、预估收入比例、未来毛利和已实现回款分开记录，未建立小米与美光之间的直接供应关系。当前没有价格与事件增量检验、估值预期证据或冻结样本外收益结果。

## 时间与可复核限制

案例分别记录财期、文件落款、可确认的公开日期、`firstPublicAt`、本次核查时刻和页面定位。精确首次公开时间未核实时保持 `null`；小米8月18日落款不代替该 PDF 首次上线日期。当前案例不符合历史信号输入条件，也不把10月核查到的资料回填到财期末。

页面及官方 PDF 文本已直接核查；没有留存可再分发的全文、页面图片或官方原件字节哈希。链接内容可能修订。导出的 `caseHash` 只证明本地案例 JSON 一致，不证明官方文档真实性或其历史可得性。公司披露是该公司的原始陈述，仍可能修订；多个页面不能变成多个独立来源。摘要由本项目自写，不复制付费全文，不把公开可读等同于原文可自由再分发。

此示例不使用私人聊天、私人缓存、家庭或账户材料，也不宣称任何私有数据 alpha。后续若要测收益，先补精确可得时间、来源版本和许可，再冻结基线、成本、样本分割与失败判据。
