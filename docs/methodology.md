# 评价契约 v0.1

## 价格和时间

价格柱是 `t: 0..719` 的合成 close。它们不是日历日，不计算年化收益、Sharpe 或真实市场概率。人工 regime 与冲击只用于验证流程。浮点计算用于研究近似；奖池整数分配使用 BigInt 中间乘积。

`w[t]` 是这一根收益区间的仓位，严格由 `close[t-2] / close[t-2-lookback] - 1` 的符号决定。信号 t−2，模拟执行 t−1，收益 t−1 到 t。参数只支持离散长仓 1 或现金 0，无仓位优化、借贷、做空、杠杆或资金费。

成本率 `c = (feeBps + slippageBps)/10000`；费用扣减 `paid = equityBefore × abs(w[t]-w[t-1]) × c`；净值 `equityAfter = (equityBefore-paid) × (1+w[t]×priceReturn[t])`。每个独立评价段从现金、净值 1 开始，最后一根柱平仓并扣费。最大回撤为所有步骤 `1-equity/runningPeak` 的最大值，runningPeak 初始为 1。`costPaid` 是各时点扣减费用之和，相对段初单位；`costDrag` 是最终无成本净值与有成本净值之差，两者因复利不同。

这是固定价位的 paper ledger，假定可以按指定 close 成交；滑点作为固定比例成本。没有盘口、部分成交、延迟随机性、市场冲击、税费、分红、资金费、停牌或存活偏差模型。`simulated_fill` 不是交易所回执。

## 切分与选择

所有区间左闭右开，区间值表示“收益终点”的索引：训练 `[42,360)`，验证 `[362,540)`，保留 `[542,720)`。42 提供 40 根回看与执行延迟的暖身。每个评价段可以读取该段之前的价格作为特征，不能读取未来的收益。

单柱收益标签不重叠。两根柱间隔是保守的边界约定，不声称是通用 purge 算法或能解决所有泄漏。若未来加入多柱标签，应按真实标签起止时间 purge，而不是照搬此间隔。

只按训练得分选前 3，再按验证净值增长为正、回撤≤20%筛选；验证得分最高者冻结。平局按候选 ID 稳定排序。无合格者现金。保留段仅评价冻结规则与基线，费用诊断不能反向重选。所有候选训练/验证指标、合格状态、淘汰原因均输出。

Rolling-origin 三折位于训练/验证开发区间，每一折用此前扩展训练段选择，然后对之后的段评价；每折保留全部训练得分。最终保留段不用于这些折。它们展示时序评价工程，不是三个独立收益证明。重复种子、成本、候选或模型输出都是额外试验，应累积记录；8 个候选预算不控制跨实验的统计选择偏差。

## 冻结与前瞻

报告留存本地冻结时间、完整协议、SHA-256、策略、数据、引擎版本。此 hash 不是外部可信时间戳。`prospective-pending` 和 0 条前瞻观测不可被当前历史或合成检验改为通过。产品当前没有实时前瞻执行器。

即使 CSV 只把较早区间给 LLM，预训练也可能包含后续市场知识；“按时间切分”不足以证明真正未见。模型若参与候选构造，知识截止和 provenance 需要随协议记录。已反复研究的 2022 H2/Q4 属于开发资料，也不能按重叠季度重复计为独立证据。

背景：[时间序列交叉验证](https://otexts.com/fpp3/tscv.html)，[金融 LLM 评价的偏差问题](https://proceedings.mlr.press/v306/kong26i.html)。PBO/DSR、多市场验证、独立前瞻观测是未来工作，本版没有实现或报告这些结果。
